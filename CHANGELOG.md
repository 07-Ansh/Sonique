# Release 1.1.0

### ✨ New Features
*   **Player Ambience**: Implemented **Ambient Mode** in the music player for an immersive visual experience.
*   **Speed Dial**: Introduced a new "Speed Dial" section on the Home Screen (3x3 grid) for quicker access to your favorite content.
*   **Settings Updates**: Added a dedicated **Update Section** in Settings to check for and manage app updates.
*   **Home UI**: Added the application icon to the top header for better branding.

### 💄 UI/UX Improvements
*   **Cleaner Home**: Redesigned the Home Screen layout for a cleaner, more streamlined browsing experience.
*   **Player Controls**: "Shuffle" and "Repeat" buttons are now greyed out when inactive, making the player state much clearer.
*   **Playback Settings**: Added controls for **Ambience Mode** in the Playback Settings.

### ⚡ Performance & Stability
*   **Smooth Playback**: Optimized the music player for error-free, seamless playback.
*   **Production**: Removed debug logs and console prints for a cleaner, more performant deployment.

### 🐛 Bug Fixes
*   **Now Playing**: Fixed an issue where the song title in the player header would not update when the track changed.

### 🔧 Technical
*   **Dependencies**: Updated project dependencies to their latest versions.
